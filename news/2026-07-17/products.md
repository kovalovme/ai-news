# Products — 2026-07-17

## NotebookLM Rebrands as Gemini Notebook <a id="gemini-notebook"></a>

**Source:** [Google Blog](https://blog.google/innovation-and-ai/products/gemini-notebook/notebooklm-gemini-notebook/) · **Type:** update · **Time (UTC):** Jul 16 ~16:00

Google renamed NotebookLM to Gemini Notebook, updated the app's logo to the blue-purple Gemini gradient, and announced two functional additions: in-notebook code execution (rolling out to Pro users), and integration with Google Search's AI Mode so that Notebooks will soon be discoverable and openable from search results. The product has 30 million users across 600,000+ organisations. The rebrand drops the "language model" jargon in favour of the Gemini brand family. No pricing changes were announced.

**Why it matters:** The Search integration is the substantive change — it gives Gemini Notebook a distribution surface tied to Google's primary consumer entry-point, potentially bypassing the bookmarked-app behaviour that limits researcher tools. Code execution upgrades it from a note-synthesis tool to a lightweight data-analysis environment for non-engineers.

## ZTE Nubia NaviX Ultra: "World's First" AI Agent Smartphone Debuts at WAIC <a id="nubia-navix-ultra"></a>

**Source:** [Notebookcheck](https://www.notebookcheck.net/Nubia-unveils-NaviX-Ultra-as-world-s-first-AI-agent-smartphone.1344390.0.html) · **Type:** launch · **Time (UTC):** Jul 17 ~02:00

ZTE's subsidiary Nubia unveiled the NaviX Ultra at WAIC 2026, calling it the world's first AI agent smartphone. Unlike earlier "AI phones" that route queries to a cloud assistant, the NaviX Ultra runs a GUI agent architecture on-device: the LLM can see and operate the phone's entire UI, execute multi-step cross-app workflows, and route heavier tasks to the cloud via ByteDance's Doubao AI backend. A physical orange "AI button" on the frame triggers the agent context. Hardware details (processor, battery, sensors) were not confirmed at launch; industry leaks suggest a 5th Gen Snapdragon 8 Elite and BOE display panel.

**Why it matters:** GUI agents that can automate arbitrary phone workflows represent a meaningful shift from chatbot integrations — the phone becomes an agent runtime rather than an interface that surfaces one assistant. If the on-device component is genuinely capable (not just a thin wrapper routing everything to Doubao), this will pressure Apple and Samsung to accelerate on-device agent architectures beyond Siri and Galaxy AI.
