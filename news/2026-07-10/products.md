# Products — 2026-07-10

## Claude Reflect: usage analytics and wellbeing dashboard <a id="claude-reflect"></a>

**Source:** [Anthropic](https://www.anthropic.com/news/reflect-with-claude) · **Type:** launch · **Time (UTC):** July 9

Anthropic launched Claude Reflect in beta on July 9 — a usage dashboard inside Claude's web and desktop apps that shows users how they interact with the model over 1, 3, 6, or 12-month windows. The feature surfaces topics, task types, usage peaks, and a "4D AI Fluency" analysis across Delegation, Description, Discernment, and Diligence. Wellbeing controls let users configure quiet hours and break reminders. Reflect is opt-in (requires Memory enabled), excludes incognito sessions and health-integration data, and is available across Free, Pro, and Max plans.

**Why it matters:** As regulators and researchers scrutinize over-reliance on AI, Anthropic is building transparency tooling directly into the product rather than treating it as a compliance add-on. TechCrunch noted the design also implicitly reinforces Claude's value by surfacing how deeply users depend on it.

## ChatGPT Work launches; Codex merges into desktop app; Atlas browser deprecated <a id="chatgpt-work-atlas"></a>

**Source:** [MacRumors](https://www.macrumors.com/2026/07/09/openai-chatgpt-work/) · **Type:** launch · **Time (UTC):** July 9, ~14:00

OpenAI shipped three simultaneous changes on July 9:

1. **ChatGPT Work** — An agent mode inside ChatGPT that takes a goal, gathers context across connected apps and files, breaks it into steps, and returns finished outputs (spreadsheets, slides, docs, shareable web apps). Powered by GPT-5.6. Rolling out to Pro, Enterprise, and Edu first; Plus and Business within days.

2. **New ChatGPT desktop app** — Unifies Chat, Work, and Codex into one app for Mac and Windows across all plans (including Free). Includes a built-in browser for agentic tasks and a remote cloud browser for background agent work.

3. **Atlas browser deprecation** — OpenAI's standalone AI browser (launched October 2025) is being discontinued with a deprecation date of August 9, 2026. Its agentic browsing capabilities migrate into the desktop app and a new ChatGPT Chrome extension.

**Why it matters:** Consolidating Codex, Work, and browsing into one desktop entrypoint brings OpenAI's agentic surface to Free-tier users for the first time, while also shutting down a side product that CEO of Applications Fidji Simo reportedly flagged as a "side quest." The Chrome extension is a direct play for ambient context that competes with Anthropic Claude Code's IDE integrations.

## Google AlphaEvolve generally available on Google Cloud <a id="alphaevolve-ga"></a>

**Source:** [Google Cloud Blog](https://cloud.google.com/blog/products/ai-machine-learning/alphaevolve-is-available-for-everyone) · **Type:** release · **Time (UTC):** July 9–10

Google made AlphaEvolve generally available on the Gemini Enterprise Agent Platform for all Google Cloud customers. AlphaEvolve is a Gemini-powered agent that takes a seed algorithm and an evaluator script, then autonomously searches for improved implementations — returning human-readable, production-ready code. It targets algorithmic optimization problems in logistics, chip design, genomics, and ML pipelines.

| Early adopter | Domain | Reported result |
|---------------|--------|-----------------|
| BASF | Supply chain | 80% forecasting improvement |
| FM Logistic | Warehouse routing | 10.4% efficiency gain (15,000+ km/yr saved) |
| Kinaxis | Demand forecasting | 22% accuracy gain + 90% runtime reduction |
| Klarna | ML pipelines | 2× throughput + improved model quality |
| JetBrains | IDE performance | 15–20% improvement |
| PacBio | Genomics | 30% reduction in sequencing errors |
| Google internal | Spanner | 20% write-amplification reduction |

**Why it matters:** AlphaEvolve moves Anthropic-style agentic code generation into the algorithm-discovery space rather than application-layer coding. Integrations with Claude Code and JetBrains IDE (Antigravity) are listed in the launch documentation, meaning engineers can invoke it from their existing toolchain.
