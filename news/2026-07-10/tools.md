# Tools — 2026-07-10

## Kimi K2.7 Code reaches Copilot Business and Enterprise <a id="kimi-k27-copilot-enterprise"></a>

**Source:** [GitHub Changelog](https://github.blog/changelog/2026-07-07-kimi-k2-7-now-available-for-copilot-business-and-enterprise/) · **Type:** update · **Time (UTC):** July 7

Moonshot AI's Kimi K2.7 Code — a trillion-parameter open-weight mixture-of-experts model — became the first open-weight model selectable in the GitHub Copilot model picker. It reached Copilot Pro/Pro+/Max on July 1 and expanded to Copilot Business and Enterprise on July 7, hosted by GitHub on Microsoft Azure and billed at provider list rates under Copilot's usage-based billing. Admins must explicitly enable the Kimi K2.7 Code policy in Copilot settings; it is off by default for Business and Enterprise plans.

| Detail | Value |
|--------|-------|
| Architecture | ~1T-parameter open-weight MoE |
| Hosting | Microsoft Azure (GitHub-managed) |
| Billing | Provider list rates (usage-based) |
| Admin default | Off for Business/Enterprise |
| Weights | Public on Hugging Face |

**Why it matters:** Copilot is the highest-distribution IDE coding assistant; adding an open-weight model means enterprises can audit the architecture and potentially self-host while keeping the same Copilot UX. The 19-day gap from weights publication (June 12) to Copilot GA (July 1) is one of the fastest open-weight-to-enterprise-IDE integrations on record.
