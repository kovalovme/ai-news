## Gemini 3.5 Pro: pricing leaks, confirmed rebuild <a id="gemini-35-pro-leaks"></a>

**Source:** [TechTimes](https://www.techtimes.com/articles/319877/20260708/gemini-35-pro-targets-july-17-deepseeks-july-24-deadline-hits-developers-now.htm) · [X / Pankaj Kumar](https://x.com/pankajkumar_dev/status/2075583824965300705) · **Type:** leak/preview · **Time (UTC):** —

New third-party reporting firms up the Gemini 3.5 Pro picture ahead of its July 17 target date (July 24 fallback). Google discarded the original 2.5 Pro checkpoint entirely and ran a fresh pretraining pass — reportedly the first time DeepMind has scrapped a production base mid-cycle rather than post-training over it. Leaked spec: 2M token context, Deep Think reasoning mode, $15/$60 per MTok (input/output), and sharply improved frontend code generation including one-shot UI and SVG production. Sound and music generation via the Fable integration is also listed. No official model card or benchmark has been published.

**Why it matters:** At $15/$60, Gemini 3.5 Pro would price above Claude Sonnet 5 ($3/$15 standard) but below Fable 5 ($10/$50), carving out a mid-to-upper frontier tier. The fresh pretraining run means benchmark comparisons against 2.5 Pro are unlikely to extrapolate cleanly.

## "Honeycomb EAP" surfaces in Cursor — probable Opus 5 preview <a id="honeycomb-opus-5-leak"></a>

**Source:** [thewincentral.com](https://thewincentral.com/claude-opus-5-leak-1m-context-window-launch/) · **Type:** leak · **Time (UTC):** ~Jul 8, brief appearance

A model labelled "Claude Honeycomb EAP" appeared briefly in Cursor's model selector on July 8 before being removed within hours. The visible spec sheet listed a 1M token context window and a fallback to Opus 4.8 safety classifiers — a profile consistent with Opus 5 rather than a Sonnet-tier model (Haiku is expected at 300K context). Anthropic has made no comment. Community timelines now forecast an Opus 5 launch by month-end, though that remains unconfirmed speculation.

**Why it matters:** If accurate, Opus 5 would be the first Anthropic flagship model since the Fable 5 launch in April. The 1M context window would match Muse Spark 1.1's context ceiling.
