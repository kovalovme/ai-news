# Products — 2026-07-22

## Mistral Medium 3.5 and OCR 4 Available in Microsoft Foundry and Copilot Studio <a id="mistral-azure-foundry"></a>

**Source:** [Microsoft Source](https://news.microsoft.com/source/2026/07/21/microsoft-and-mistral-expand-strategic-partnership-to-give-enterprises-and-regulated-industries-frontier-ai-they-can-control/) · **Type:** launch · **Time (UTC):** Jul 21 ~14:00

As part of the Microsoft-Mistral partnership expansion, Mistral Medium 3.5 (128B parameters, 262K-token context, 77.6% SWE-Bench Verified, dual fast/reasoning modes) and Mistral OCR 4 are now available through Microsoft Foundry and Copilot Studio for development, customization, and deployment. Organizations on Azure can switch between cloud-hosted Foundry, cloud-connected Azure Local (for data residency requirements), and fully air-gapped Azure Local (zero internet connection) using the same model surface.

**Why it matters:** Adding air-gapped frontier-model access to Azure Local gives regulated industries — healthcare, financial services, critical infrastructure — a path to frontier AI under their own infrastructure without an internet dependency, addressing a gap that has kept several EU sectors on smaller on-premise models.
