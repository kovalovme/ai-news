# Models — 2026-07-14

## Claude Sonnet 5 becomes the default model in Claude Code <a id="claude-sonnet-5-default"></a>

**Source:** [Anthropic](https://www.anthropic.com/claude/sonnet) · **Type:** update · **Time (UTC):** —

Anthropic quietly rolled out Claude Sonnet 5 as the default model for Claude Code and for Free and Pro users on claude.ai. The model ships with a native 1M-token context window and is offered at an introductory API price of $2 input / $10 output per million tokens through August 31, 2026, after which pricing rises to $3/$15 per MTok. The previous default was Claude Sonnet 4.

**Why it matters:** The Sonnet 5 upgrade increases the context budget available to agentic loops without changing plan tiers, and the promotional pricing undercuts GPT-5.6 Sol ($5/$30) and Terra ($2.50/$15) for users already in the Claude ecosystem. The August 31 pricing cliff gives developers roughly seven weeks to benchmark cost before locking in integrations.

| Tier | Intro price (per MTok) | Post-Aug 31 |
|------|----------------------:|------------:|
| Sonnet 5 input | $2.00 | $3.00 |
| Sonnet 5 output | $10.00 | $15.00 |
